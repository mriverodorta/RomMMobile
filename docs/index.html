Android 8 or later · RomM 5.x

Features

Keep your progress.

Sync in-game saves and save states separately. RomMMobileS reads your ES-DE setup and can restore incoming files when RetroArch has quit.

Take your library.

Browse platforms and collections, check what is installed, and download games and BIOS files into your frontend’s folders.

Use your own server.

Connect to the RomM server you run. Use an HTTP address on your local network or an HTTPS address for remote access.

Setup

Start with your handheld.

Save sync was tested with RomM 5.4.1, ES-DE, and RetroArch on Retroid Pocket Classic and Anbernic RG476H.

Read the full setup guide ↗
  1. Install and connect. Install the signed APK and sign in to your RomM server.
  2. Choose your folders. Select ES-DE and the ROM folder it uses. Grant access to your shared RetroArch save folders.
  3. Turn on save sync. Choose battery saves, states, or both. Grant Usage Access for automatic restore.

Before you switch devices

Use the same RomM account and matching ROM files on each device. Save states also need compatible RetroArch core builds.
